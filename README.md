# Online Shopping Website

## Features
- User registration
- Product listing
- Add to cart
- Search products
- Checkout

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open the project folder
3. Open index.html in a browser
